To save a key, enter the API key, enable Remember, enter your Vault passphrase, and click Save encrypted API key. The API key field stays empty when reopening the popup, even when a key is saved. Your password manager may offer to fill the vault passphrase. Autofill support varies in Chrome extension popups. The passphrase is not saved by this extension. Unlock once per browser session. A lost passphrase cannot be recovered.
